## Notes de câblage (après validation)

- Volume demandé : 27 sources par format, puis 9 imports par jour et par
  format (règle 1 contenu/source/24 h compatible : 27 > 9).
- Vidéos et lives : embed YouTube (youtube-nocookie.com) à autoriser dans
  la CSP `frame-src` (comme le fix tuiles V2.6.87). Embed dérivable du
  lien source, pas de migration de base.
- Lives : onglet distinct, sources marquées « lives » ci-dessus.
- Podcasts : lecteur audio HTML5 (l'enclosure du flux) ou lien source.
- Dessins : l'image EST le contenu (grand format dans la carte).
- Toujours : titre, tags (lib/import-breves/tags.ts), nom du média
  source en sur-titre, « Lire/Écouter/Regarder sur le site source » ↗.
- Les 3 logiques sur chaque onglet : à la une, bandeau La rédaction,
  séparateur « Revue de presse » avant les contenus externes.
